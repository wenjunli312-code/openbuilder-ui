Architecture

三层架构，职责清晰

Backend 只做 API + 调度，编译由 openbuilder CLI 通过 Docker 调用专用交叉编译镜像完成，产物上传 S3 持久化存储。

Frontend

单页 HTML + Vanilla JS

零框架，响应式布局，可直接在浏览器或 WebView 中运行

Backend

Flask API (Python)

接收请求，调度 openbuilder CLI，写入 builds.json 状态

Build Runner

openbuilder CLI + Docker

通过 Docker 启动 dockcross 编译镜像，跨平台交叉编译

Storage

MinIO (S3 兼容)

编译产物 target.tar.gz + 构建元信息 JSON

🌐

Flask REST API

完整的 REST 接口：POST /api/builds 发起构建，GET /api/builds 获取列表，支持构建日志流式读取和产物下载。

🐳

Docker 隔离编译

Backend 容器只运行 Flask，不装编译工具。编译通过 Docker Socket 启动 dockcross 镜像（arm64/armv7/x64），用完即销毁。

☁️

S3 产物持久化

编译产物按 platform/mode 打包上传 S3，以 build ID 为 key，支持 30 天留存和任意回溯下载。

🔄

Build 比较引擎

比较两次构建的 project / platform / mode / mode 是否相同，列出 repo 级别的 commit 差异和 GitHub 对比链接。

Backend API

Flask REST 接口

所有交互通过 HTTP API 完成，Backend 只负责任务调度和数据存储。

发起一次新的跨平台编译
POST /api/builds { "project": "perception-core", "platform": "linux-arm64", "mode": "release", "target": "perception-core", "manifest": "#manifest.yaml 内容..." } # Response { "id": "20260515_102400", "status": "pending" }
获取所有构建列表

Cross-Platform

一次配置，三大平台

同一个 manifest，同一份源码，通过选择不同 platform 完成 ARM64 / ARMv7 / x86_64 的交叉编译。

linux-arm64 — ARM 64-bit（嵌入式主流量产平台）
linux-armv7 — ARM 32-bit（成本敏感型设备）
linux-x86_64 — x86 桌面开发/测试
Docker

dockcross 交叉编译镜像

Backend 不装编译器，通过 Docker Socket 启动 dockcross 容器执行交叉编译。镜像内含完整的 gcc / cmake / sysroot，用完即销毁，不污染宿主机。

S3

按平台隔离存储

产物打包粒度精确到 target/{platform}/{mode}/，避免不同平台的产物混在一起。S3 key 格式：build/{id}/target-{id}.tar.gz。

Cache

Workspace Pool 复用

源码克隆到 workspace pool 的独立目录，CMake 缓存跨次复用。S3 产物按 manifest content hash 缓存命中，直接跳过重复编译。

Quick Start

5 分钟跑起来

1. 克隆项目
git clone https://github.com/wenjunli312-code/openbuilder-ui.git cd openbuilder-ui
2. 配置 GitHub Token（访问私有仓库需要）
echo "GITHUB_TOKEN=ghp_xxxx" > .env
3. 一键启动
docker compose up -d # 打开 http://localhost:8080
通过 API 发起构建
curl -X POST http://localhost:8080/api/builds \ -H "Content-Type: application/json" \ -d '{ "project": "perception-core", "platform": "linux-arm64", "mode": "release", "target": "perception-core", "manifest": "repos:\n - name: sensor-abstraction\n url: https://github.com/owner/sensor-abstraction\n revision: main\n - name: vehicle-bridge\n url: https://github.com/owner/vehicle-bridge\n revision: develop\n" }' # 返回：{"id": "20260515_102400", "status": "pending"}
实时查看构建日志
curl http://localhost:8080/api/builds/20260515_102400/log # 返回：{ "status": "running", "log_length": 1234, "log_tail": "..." }
下载编译产物
curl -O http://localhost:8080/api/builds/20260515_102400/download # 下载 target-20260515_102400.tar.gz
